# Проект «Благо»

## Описание проекта

«Благо» — это информационный веб-сайт, созданный в рамках проектной практики.  
Главная цель проекта — разработка удобного и современного сайта с полезной социальной информацией для пользователей.

На сайте размещены:
- информация о проекте;
- журнал разработки;
- материалы и полезные ресурсы;
- информация об участниках проекта.

Проект был реализован с использованием HTML и CSS без применения сторонних фреймворков.

---

## Цели проекта

Во время разработки проекта были поставлены следующие задачи:

- изучить основы веб-разработки;
- научиться создавать структуру сайта на HTML;
- освоить стилизацию интерфейса с помощью CSS;
- организовать совместную работу команды через GitHub;
- оформить документацию проекта в формате Markdown.

---

## Этапы разработки

### 1. Планирование проекта

На первом этапе команда определила:
- тематику сайта;
- структуру страниц;
- внешний стиль проекта;
- распределение обязанностей между участниками.

Были созданы первые наброски интерфейса и определены основные разделы сайта.

---

### 2. Создание структуры сайта

После планирования была реализована базовая HTML-структура:

- главная страница;
- страница «О проекте»;
- страница участников;
- журнал проекта;
- страница ресурсов.

Также было добавлено навигационное меню для перехода между разделами.

---

### 3. Разработка дизайна

На данном этапе команда занималась:
- подбором цветовой палитры;
- оформлением блоков;
- настройкой шрифтов;
- созданием адаптивного расположения элементов.

Для улучшения внешнего вида были добавлены:
- эффекты наведения;
- анимации;
- карточки новостей;
- тени и скругления.

---

### 4. Наполнение контентом

После завершения основной верстки сайт был заполнен текстовой информацией:
- описаниями проекта;
- журналом разработки;
- полезными материалами;
- ссылками на внешние ресурсы.

Для страницы «Журнал» были подготовлены большие публикации о процессе разработки сайта.

---

### 5. Работа с GitHub

Для совместной разработки использовался GitHub.

Участники проекта:
- загружали изменения в репозиторий;
- обновляли файлы проекта;
- работали с документацией;
- координировали изменения между собой.
