## Формулировка задания вариативной части

В рамках проектной практики необходимо было разработать многостраничный информационный веб-сайт с использованием HTML и CSS.

В ходе выполнения задания требовалось:
- создать структуру сайта;
- реализовать навигацию между страницами;
- оформить пользовательский интерфейс;
- разработать раздел «Журнал» с публикациями о ходе работы;
- подготовить документацию проекта;
- использовать Markdown для оформления материалов;
- организовать совместную работу через GitHub.

---

## Краткое описание проекта

Проект «Благо» представляет собой информационный веб-сайт, созданный в рамках проектной практики.

Сайт включает:
- главную страницу;
- раздел «О проекте»;
- страницу участников;
- журнал проекта;
- страницу ресурсов.

Во время разработки использовались:
- HTML5;
- CSS3;
- GitHub;
- Markdown;
- Visual Studio Code.

Получение практических навыков веб-разработки, командной работы и оформления документации при создании современного информационного сайта.
